# Memory Island — концепция и визуальная система (1 страница)

> **English summary.** A photograph remembers how a day looked, not how it felt. Memory Island turns one day — a text, photographs and a song — into a living procedural flower on a floating cloud island: planet → years → twelve month-islands → garden of the month → one flower per recorded day. Text drives shape and light, photographs drive colour, music drives movement; every decision is recorded as a reason and shown in the panel "Why does my flower look like this?". No AI model runs at runtime, everything is stored in the browser, and privacy is enforced when a planet is exported to a friend. Step-by-step usage: [USER-GUIDE.md](USER-GUIDE.md); judges' walk-through: [../QUICK-START.md](../QUICK-START.md).

## Идея
Фотографии хранят, как день выглядел, но не как он ощущался. Memory Island превращает один день — текст, фото и песню — в **живое растение** на летающем облачном острове. Планета пользователя делится на годы, год — на двенадцать островов-месяцев, у каждого свой сад. Один записанный день = один цветок. Со временем пустые сады становятся живыми архивами. Открыв цветок через год, человек снова видит фотографии, читает собственные слова и слышит ту песню — и вспоминает не событие, а чувство.

## Аудитория
Люди 16–35, которые ведут (или хотели бы вести) дневник, но которым не хватает мотивации: мы заменяем «запись в список» на выращивание маленького мира. Второй круг — друзья: планету можно показать, открыв лишь выбранные дни.

## Формат результата
Интерактивная 2D-сцена: процедурный SVG-цветок в саду месяца + три «лепестка» (фото, история с цитатой, музыка) + панель «Почему мой цветок такой?». Экспорт: «папка дня» (zip: story.txt, memory.json, photos/, песня или ссылка, flower.svg).

## Постоянные элементы (делают ленту цельной)
- Полуночно-синее небо со звёздами, розово-лавандовые облака, зелёные сады; кремовый текст, золотые акценты.
- Один и тот же анатомический каркас растения: стебель из одной точки, листья, венчик с сердцевиной, кольцо пыльцы, ореол свечения.
- Шрифты: Cormorant Garamond (заголовки, цитаты) + Nunito (интерфейс). Дата и название всегда в одном месте.
- Название дня: 3–7 слов, компоновка «[прилагательное] главное-существительное [место] [с кем / и что]» из существительных, найденных в записи («Ночь в офисе и дедлайн», «Зимний вечер с бабушкой»).

## Переменные элементы (меняются с настроением, фото и музыкой)
| Параметр растения | Чем управляется |
|---|---|
| Форма лепестков (мягкие, заострённые, многослойные, угловатые, колокольчик, тонкие, звёздчатые) | голосование эмоций: спокойствие+тепло → мягкие; напряжение → угловатые; радость+люди → многослойные; грусть+ностальгия → колокольчик; удивление+ночь → звёздчатые. Смешанные эмоции → внутренний слой другой формы |
| Число лепестков и слоёв | сложность записи (богатство словаря, число тем), радость, энергия |
| Цвета лепестков | доминирующие цвета фото (k-means), гармонизированные в палитру мира; сдвиг к тёплому/холодному по тексту; при отсутствии цветных фото — палитра по теплу дня |
| Стебель | спокойствие → плавный синусоидальный изгиб; напряжение → изломы (1–5 по силе напряжения) |
| Листья | природа и сложность → количество; напряжение → зубчатые, спокойствие → округлые |
| Свечение | ночь, ностальгия, удивление; усиливается при открытии лепестков |
| Покачивание и пульс | **темп песни (BPM)** → скорость покачивания, период пульса свечения = 2 удара; энергия песни → амплитуда; анимация прорастания тоже идёт в темпе песни |
| Частицы | радость → искры; спокойствие → дымка; напряжение → вспышки; ностальгия/грусть → опадающие лепестки; ночь → светлячки |
| Фактура лепестков | спокойствие+тепло → мазки (Моне); напряжение → линии и точки (Кандинский); праздник → золотые пятна (Климт); тихая грусть → тушевой контур (японская графика) |
| Напряжение + облегчение | холодное основание и тёплые кончики лепестков: день, который «прошёл от стресса к выдоху» |

## Правило честности
Ни один параметр не случаен: каждое решение записывается как причина и показывается пользователю. Из ссылки на стриминг нельзя получить аудио — тогда характер песни задаёт пользователь, и интерфейс говорит об этом прямо. Низкая энергия или грусть не делают цветок меньше или хуже: они меняют характер, а не ранг. Оценка эмоций — художественная интерпретация, не диагностика.
